# CpuStaticViewer (3D Viewer на Qt + OpenGL 3.3)

## 1. Назначение и краткое описание

**CpuStaticViewer** — настольное приложение для визуализации трёхмерных моделей формата **Wavefront OBJ** с интерактивным управлением камерой и параметрами отображения (рёбра, вершины, заливка, фон, тип проекции). Рендеринг выполняется на базе **OpenGL 3.3 Core** в контексте `QOpenGLWidget` фреймворка :contentReference[oaicite:0]{index=0}; матричная математика и преобразования реализованы на стороне CPU (собственный класс матриц).

Приложение ориентировано на:
- быстрый просмотр моделей,
- отладку геометрии (рёбра/вершины),
- контроль визуальных параметров (цвета, пунктир, толщина, размер вершин),
- воспроизводимость результатов (сохранение снимка экрана).

---

## 2. Основные возможности

### 2.1. Геометрия и формат данных
- Загрузка моделей из `.obj` (вершины `v`, грани `f`).
- Построение:
  - массива вершин (XYZ),
  - списка рёбер (уникальные рёбра, получаемые из граней),
  - списка треугольников (при наличии триангуляции в парсере).
- Отображение служебной информации:
  - имя текущего файла,
  - количество вершин,
  - количество рёбер.

### 2.2. Режимы отображения
- **Рёбра**
  - включение/выключение,
  - цвет рёбер,
  - толщина (ограничения платформы см. §7.2),
  - пунктирная линия (параметры «шаг» и «заполнение»).
- **Вершины**
  - режим: отсутствует / круг / квадрат,
  - размер,
  - цвет.
- **Заливка граней**
  - включение/выключение,
  - цвет заливки,
  - прозрачность (дискретный режим 0/1 либо настраиваемая альфа — зависит от текущей конфигурации UI).
- **Фон**
  - выбор цвета фона.
- **Сохранение изображения**
  - экспорт текущего кадра в BMP/JPEG.

### 2.3. Камера и матрицы
- Две проекции:
  - **параллельная (ортографическая)**,
  - **центральная (перспективная)**.
- Матрица `MVP` строится на CPU:
  - `M` — матрица модели (поворот/масштаб),
  - `V` — матрица вида (перемещение «камеры»),
  - `P` — матрица проекции.

## 3. Управление (клавиатура)

> Точные бинды могут быть изменены в коде; ниже приведён актуальный набор для `GlWidget`.

### 3.1. Поворот модели
- `I / K` — вращение вокруг **X** (±)
- `J / L` — вращение вокруг **Y** (±)
- `U / O` — вращение вокруг **Z** (±)

### 3.2. Перемещение/масштаб проекции
- `W / S`
  - в перспективе: движение по оси Z (приближение/удаление),
  - в ортографической проекции: изменение масштаба проекции (zoom).
- `A / D` — смещение по X
- `Q / E` — смещение по Y

### 3.3. Переключатели
- `P` — переключение **типа проекции**
- `Z` — переключение **заливки граней**

## 4. Интерфейс

### 4.1. Верхняя панель вкладок
- **Проекция** — тип проекции, точные углы поворота (спинбоксы), (опционально) масштаб модели.
- **Рёбра** — пунктир, толщина, параметры пунктира, цвет рёбер.
- **Вершины** — режим, размер, цвет вершин.
- **Покраска** — фон и параметры заливки (в зависимости от конфигурации UI).
- **Файл** — загрузка модели и сохранение изображения.

### 4.2. Информационная строка (главный интерфейс)
Отображает:
- **имя текущего файла**,
- **число вершин**,
- **число рёбер**.

Строка скрывается при открытии панели настроек и автоматически возвращается при закрытии.
