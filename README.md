# 3DViewer (Qt + OpenGL) — минимальный тестовый рендер

## Что это
Крайне компактный «скелет» 3D-вьювера: `QOpenGLWidget` создаёт контекст, `GlRender` грузит шейдеры и меш в GPU (VAO/VBO/EBO), далее каждый кадр собирается `MVP = P * V * M` и рисуются рёбра (и опционально заливка).

## Управление (клавиши)
**Вращение модели:**
- `I/K` — X +
  / X -
- `J/L` — Y +
  / Y -
- `U/O` — Z +
  / Z -

**Движение камеры (сдвиг вида):**
- `W/S` — вперёд / назад
- `A/D` — влево / вправо
- `Q/E` — вниз / вверх *(если включено в TickInput_())*

**Переключатели:**
- `P` — перспектива ↔ ортография
- `Z` — заливка граней on/off

## Что рисуется
- Каркас: `GL_LINES` по `edge_indices`
- Заливка (если включена и есть `tri_indices`): `GL_TRIANGLES`
